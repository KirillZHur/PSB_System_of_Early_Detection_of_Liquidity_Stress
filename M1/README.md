# Модуль М1 — Усреднение обязательных резервов

## Описание модуля

Модуль М1 предназначен для выявления признаков стресса ликвидности банковского сектора на основе механизма усреднения обязательных резервов Банка России.

Экономическая логика модуля основана на предположении, что в периоды повышенного напряжения банки начинают удерживать на корсчетах объёмы средств, значительно превышающие обязательный норматив резервирования. Одновременно с этим растёт ставка RUONIA, отражающая стоимость краткосрочной ликвидности на межбанковском рынке.

Модуль автоматически собирает данные ЦБ РФ, рассчитывает спред между фактическими остатками и обязательными резервами, выполняет MAD-нормализацию сигналов и формирует итоговый индикатор M1_signal.

Основной источник:

https://www.cbr.ru/hd_base/RReserves/

Excel-файл:

https://www.cbr.ru/vfs/hd_base/RReserves/required_reserves_table.xlsx

Используемые показатели:

* фактические среднедневные остатки на корсчетах
* обязательные резервы
* обязательные резервы на счетах учета
* период усреднения

## RUONIA

Источник:

https://www.cbr.ru/hd_base/ruonia/dynamics/

Используемые показатели:

* ставка RUONIA
* объем сделок RUONIA

# Этапы обработки данных

## 1. Загрузка данных

Модуль автоматически:

* скачивает Excel-файл обязательных резервов
* загружает исторические данные RUONIA
* сохраняет исходные данные в папку `data/raw`


## 2. Предобработка данных

Выполняются:

* очистка таблиц
* приведение дат к формату datetime
* преобразование числовых значений
* агрегация RUONIA по месяцам
* объединение данных резервов и RUONIA


# Расчёт показателей

## Спред резервов

Формула:

```text
spread = actual_avg_balances - required_reserves
```

где:

* `actual_avg_balances` — фактические среднедневные остатки
* `required_reserves` — обязательные резервы

---

## MAD-нормализация

Для выявления аномалий используется MAD-нормализация на скользящем окне 36 месяцев.

Формула:

```text
MAD_score = (x - median(x)) / MAD(x)
```

Рассчитываются:

* `MAD_score_spread`
* `MAD_score_RUONIA`


## Итоговый сигнал модуля

Итоговый сигнал:

```text
M1_signal = 0.6 * MAD_score_spread + 0.4 * MAD_score_RUONIA
```

Отрицательные значения обрезаются до 0.


# Выходные данные

Результат сохраняется в файл:

```text
M1/data/processed/m1_reserves_signals.csv
```

Структура файла:

| Поле             | Описание                   |
| ---------------- | -------------------------- |
| date             | дата                       |
| spread           | спред резервов             |
| ruonia           | ставка RUONIA              |
| MAD_score_spread | MAD-нормализованный спред  |
| MAD_score_RUONIA | MAD-нормализованная RUONIA |
| Flag_EndOfPeriod | флаг конца периода         |
| M1_signal        | итоговый сигнал модуля     |

Графики сохраняются в папку:

```text
M1/plots/
```

# Проверка на стресс-периодах

Модуль протестирован на исторических стресс-эпизодах:

* декабрь 2014
* февраль–март 2022
* август 2023

В периоды повышенного стресса наблюдается рост M1_signal.

# Взаимодействие с другими модулями

Модуль М1 формирует независимый сигнал стресса ликвидности. Взаимосвязи с модулями М2–М5 учитываются на уровне агрегационного слоя LSI для предотвращения двойного счёта совпадающих сигналов.
