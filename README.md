# RU Liquidity Sentinel

Система раннего выявления стресса ликвидности банковского сектора.

Проект разработан в рамках кейса ПСБ и предназначен для мониторинга состояния ликвидности финансового рынка на основе макроэкономических и рыночных сигналов.

Система агрегирует данные Банка России, Федерального казначейства и налогового календаря, рассчитывает сигналы отдельных модулей и формирует единый индекс стресса ликвидности — Liquidity Stress Index (LSI).


# Основные возможности

* автоматическая загрузка и обработка данных ЦБ РФ и ФНС;
* расчёт стресс-сигналов по модулям M1–M5;
* MAD-нормализация временных рядов;
* формирование единого Liquidity Stress Index (LSI);
* интерпретация уровня стресса (зелёный / жёлтый / красный);
* расчёт вклада каждого модуля в итоговый индекс;
* визуализация динамики сигналов и индекса;
* интерактивный дашборд на Streamlit.


# Архитектура системы

Система состоит из пяти независимых расчётных модулей и агрегационного слоя:

| Модуль | Назначение |
|---|---|
| M1 | Усреднение обязательных резервов |
| M2 | Аукционы репо ЦБ |
| M3 | Размещение ОФЗ |
| M4 | Налоговый период и сезонность |
| M5 | Средства Федерального казначейства |
| aggregation | Расчёт итогового индекса LSI |

# Установка зависимостей

Из корня проекта:

```bash
pip install pandas numpy matplotlib plotly streamlit
```


# Запуск модулей

Каждый модуль запускается отдельно.

Пример:

```bash
python M1/main.py
python M2/main.py
python M3/main.py
python M4/main.py
python M5/main.py
```

После выполнения модулей формируются CSV-файлы сигналов.

# Запуск агрегационного слоя

Из корня проекта:

```bash
python aggregation/main.py
```

Результат:

* расчёт Liquidity Stress Index;
* сохранение итогового CSV;
* построение графиков.

Выходные данные:

```text
aggregation/data/processed/lsi_signals.csv
```


# Запуск дашборда

Из корня проекта:

```bash
streamlit run dashboard/app.py
```

После запуска откроется интерактивный веб-интерфейс с:

* динамикой LSI;
* статусом ликвидности;
* вкладом модулей;
* графиками сигналов;
* сезонными факторами;
* таблицами последних значений.

# Интерпретация LSI

| Диапазон | Статус |
|---|---|
| 0–40 | Нормальная ликвидность |
| 40–70 | Повышенное напряжение |
| 70–100 | Стресс ликвидности |
