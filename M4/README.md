# Модуль М4 — Налоговый период и сезонность

## Описание модуля

Модуль М4 предназначен для учёта сезонных факторов ликвидности банковского сектора, связанных с налоговыми периодами и календарными эффектами.

Экономическая логика модуля основана на предположении, что в периоды налоговых выплат юридические лица и индивидуальные предприниматели выводят средства со своих расчётных счетов для уплаты налогов. Это приводит к краткосрочному оттоку ликвидности из банковской системы, росту ставок денежного рынка и усилению спроса на инструменты рефинансирования.

Модуль автоматически формирует календарь налоговых периодов, рассчитывает сезонные флаги и создаёт Seasonal_Factor — сезонный коэффициент, используемый в агрегационном слое Liquidity Stress Index (LSI).

# Источники данных

## Налоговый календарь ФНС

Основной источник:

https://www.nalog.gov.ru/rn77/calendar/

* даты налоговых платежей

* календарные эффекты конца месяца и квартала

# Этапы обработки данных

## 1. Загрузка данных

Модуль автоматически:

* загружает страницу налогового календаря ФНС
* формирует календарь налоговых дат
* сохраняет исходные данные в папку `data/raw`


## 2. Предобработка данных

Выполняются:

* создание ежедневного календаря
* выделение налоговых недель
* расчёт флагов конца месяца
* расчёт флагов конца квартала
* подготовка сезонных факторов


# Расчёт показателей

## Tax_Week_Flag

Флаг налоговой недели:

```text
Tax_Week_Flag = 1,
если дата попадает в интервал ±7 дней
от ключевой налоговой даты
```


## End_of_Month_Flag

Флаг конца месяца:

```text
End_of_Month_Flag = 1,
если дата является последним днём месяца
```


## End_of_Quarter_Flag

Флаг конца квартала:

```text
End_of_Quarter_Flag = 1,
если дата является последним днём квартала
```


## Seasonal_Factor

Итоговый сезонный фактор:

```text
Seasonal_Factor =
1.0
+ 0.2 × Tax_Week_Flag
+ 0.1 × End_of_Month_Flag
+ 0.1 × End_of_Quarter_Flag
```

Значение ограничивается диапазоном:

```text
1.0 – 1.4
```


## Итоговый сигнал модуля

Итоговый сигнал:

```text
M4_signal = Seasonal_Factor
```

Модуль используется как сезонный мультипликатор в агрегационном слое LSI и не добавляется к другим сигналам аддитивно.

```text
M4/plots/
```


# Роль модуля в системе

Модуль М4 выступает как сезонный контекстуализатор и позволяет системе отличать структурный стресс ликвидности от предсказуемого сезонного давления.

Сигналы модуля пересекаются с модулями:

* М1 — усреднение резервов;
* М2 — аукционы репо;
* М5 — средства федерального казначейства.

Для предотвращения двойного счёта сезонных эффектов предполагается использование:

* условного взвешивания сигналов;
* STL-декомпозиции временных рядов;
* корректировки весов модулей в агрегационном слое.
