# Агрегационный слой — Liquidity Stress Index (LSI)

## Описание модуля

Агрегационный слой является финальным этапом расчётного пайплайна системы.

Он объединяет сигналы модулей M1–M5 в единый индекс стресса ликвидности — Liquidity Stress Index (LSI) в диапазоне от 0 до 100.

Агрегационный слой не собирает собственные данные, а использует готовые выходы расчётных модулей:

* M1 — усреднение обязательных резервов
* M2 — аукционы репо ЦБ
* M3 — размещение ОФЗ
* M4 — налоговый период и сезонность
* M5 — средства федерального казначейства

Главное требование к агрегации — интерпретируемость результата: для каждого значения LSI рассчитывается вклад отдельных модулей.

# Этапы работы

## 1. Загрузка данных

Модуль загружает готовые CSV-файлы из расчётных модулей:

```text
M1/data/processed/m1_reserves_signals.csv
M2/data/processed/m2_repo_signals_demo.csv
M3/src/output/auctions_enriched.csv
M4/data/processed/m4_tax_seasonality_signals.csv
M5/output/treasury_stress.csv
```

## 2. Предобработка данных

Выполняются:

* приведение дат к единому формату;
* агрегация сигналов до месячной частоты;
* объединение сигналов M1–M5 в одну таблицу;
* заполнение пропусков нейтральными значениями;
* обрезка отрицательных стресс-сигналов до 0.



# Алгоритм агрегации

## Взвешенная сумма сигналов

Для расчёта базового стресс-сигнала используется интерпретируемая взвешенная сумма:

```text
LSI_raw =
w1 * M1_signal +
w2 * M2_signal +
w3 * M3_signal +
w5 * M5_signal
```

Используемые веса:

| Модуль | Вес |
|---|---:|
| M1 | 0.25 |
| M2 | 0.30 |
| M3 | 0.20 |
| M5 | 0.25 |

Сумма весов равна 1.

---

## Учет сезонного фактора М4

Модуль M4 не добавляется к индексу как обычный стресс-сигнал. Он используется как сезонный мультипликатор:

```text
LSI_adjusted = LSI_raw * Seasonal_Factor
```

Такой подход снижает риск двойного счёта налогового эффекта.


## Масштабирование в диапазон 0–100

Для перевода итогового значения в шкалу 0–100 используется сигмоидальное масштабирование:

```text
LSI = 100 / (1 + exp(-LSI_adjusted))
```

# Интерпретация LSI

| Диапазон | Статус | Интерпретация |
|---|---|---|
| 0–40 | ЗЕЛЁНЫЙ | нормальная ликвидность |
| 40–70 | ЖЁЛТЫЙ | повышенное напряжение |
| 70–100 | КРАСНЫЙ | стресс ликвидности |


# Выходные данные

Результат сохраняется в файл:

```text
aggregation/data/processed/lsi_signals.csv
```

Основные поля:

| Поле | Описание |
|---|---|
| date | дата |
| M1_signal | сигнал модуля M1 |
| M2_signal | сигнал модуля M2 |
| M3_signal | сигнал модуля M3 |
| M5_signal | сигнал модуля M5 |
| Seasonal_Factor | сезонный фактор M4 |
| LSI_raw | базовый индекс до сезонной корректировки |
| LSI_adjusted | индекс после сезонной корректировки |
| LSI | итоговый индекс 0–100 |
| LSI_status | статус: ЗЕЛЁНЫЙ / ЖЁЛТЫЙ / КРАСНЫЙ |
| M1_share | вклад M1 |
| M2_share | вклад M2 |
| M3_share | вклад M3 |
| M5_share | вклад M5 |


# Визуализация

Агрегационный слой строит графики:

* динамика LSI;
* вклад модулей в итоговый индекс;
* LSI и сезонный фактор M4.

Графики сохраняются в папку:

```text
aggregation/plots/
```


# Запуск

```bash
pip install pandas numpy matplotlib
```

```bash
python aggregation/main.py
```

# Результат работы

После запуска:

* загружаются сигналы модулей M1–M5;
* формируется единая таблица признаков;
* рассчитывается Liquidity Stress Index;
* определяется статус уровня стресса;
* рассчитывается вклад каждого модуля;
* сохраняется итоговый CSV;
* строятся графики для отчёта и дашборда.
